=============================================================
  AI OPTI MATRIX - ONE-CLICK LAUNCH INSTRUCTIONS
=============================================================

1. Start Python Backend (FastAPI + Google Gemini Flash API):
   - Double click: start_backend.bat
   - OR run in PowerShell:
     .\backend\myenv\Scripts\python.exe -m uvicorn app.main:app --port 8000 --app-dir backend

2. Start PHP Frontend:
   - Double click: start_frontend.bat
   - OR run in PowerShell:
     php -S localhost:3000 -t frontend

3. Open in Browser:
   - URL: http://localhost:3000
